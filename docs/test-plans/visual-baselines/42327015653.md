# Test plan: visual-baselines/42327015653

## Summary

This branch adds the first Linux screenshots for the catalog visual tests: the signed-out first screen of the shop, the Monstera Deliciosa card, and the Hoya Carnosa card after a name search. No shop behavior, API, page, or component source changed. `package.json` and Playwright config did not change, so this plan does not schedule a full-suite run, a Cypress run, an API run, or an axe scan, and it does not edit `a11y-baseline.json`. The new files are the pixel oracle for `tests/visual/catalog.spec.ts` (`maxDiffPixels: 0`, project `visual`, viewport 1280×800). They matter to customers because a wrong image makes a wrong catalog look correct on the next run. The first-screen image shows Snake Plant as `$22` and ZZ Plant as `$27.5`. The Hoya image shows `$21`. Monstera shows `$34.99`. Product copy requires two decimals on every price, so the price row below stays that strict: a pixel match to these PNGs does not clear it. This plan is not approved. Rows Q1 and Q2 stay unresolved (`assumed — ask`) and get no test until a human resolves them.
